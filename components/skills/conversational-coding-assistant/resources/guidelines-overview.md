# 回答指南总览

> 如何撰写高质量的对话式回答

## 📚 回答指南体系

本指南分为三个部分，帮助你掌握对话式编程助手的核心技能：

### 1. 长度与风格指南
**文件**: [guidelines-length-and-style.md](guidelines-length-and-style.md)

**内容涵盖**:
- **回答长度决策** - 完整的决策树和对照表
- **语言风格指南** - 禁止短语、避免冗余、专业客观性

**关键原则**:
- 简单问题 → 1行
- 代码解释 → 2-4行
- 方案建议 → 5-15行
- 复杂任务 → 详细规划

**核心价值**: 学会如何精准匹配回答长度与问题复杂度

---

### 2. 工具与技巧指南
**文件**: [guidelines-tools-and-techniques.md](guidelines-tools-and-techniques.md)

**内容涵盖**:
- **工具使用策略** - AskUserQuestion, Read 工具的最佳实践
- **高级技巧** - 渐进式详细、上下文记忆、预判需求、代码引用、量化结果

**核心技巧**:
1. **渐进式详细**: 第1层（一句话）→ 第2层（简要步骤）→ 第3层（详细指导）
2. **上下文记忆**: 保持对话连贯性，记住前面的信息
3. **预判需求**: 主动提供相关后续信息
4. **代码引用**: 使用 `file:line` 精确格式
5. **量化结果**: 提供具体性能数据（如 850ms → 45ms）

**核心价值**: 提升交互质量和效率的实用技巧

---

### 3. 错误与检查清单
**文件**: [guidelines-errors-and-checklist.md](guidelines-errors-and-checklist.md)

**内容涵盖**:
- **常见错误** - 5 类典型错误和正确示例
- **回答质量自检清单** - 回答前/回答时/回答后的完整检查项
- **最佳实践总结** - DO/DON'T 快速参考

**5 类常见错误**:
1. 过度解释简单问题
2. 猜测而非询问
3. 忘记确认完成
4. 混淆不同问题类型
5. 盲目迎合错误观点

**核心价值**: 避免常见陷阱，确保回答质量

## 🎯 快速决策参考

### 回答长度速查表

| 问题类型 | 推荐长度 | 决策依据 |
|---------|---------|---------|
| 事实查询 | 1行 | 直接回答，无需解释 |
| 文件定位 | 1行 | 提供精确路径 |
| 是非问题 | 1行 | "是" 或 "否" |
| 简单解释 | 2-4行 | 概述 + 关键步骤 |
| 代码理解 | 3-5行 | 流程 + 关键点 |
| 方案建议 | 5-15行 | 2-3方案 + 对比 + 推荐 |
| 复杂任务 | 详细规划 | 澄清 + 规划 + 实施 |
| 故障排查 | 按需详细 | 定位 + 原因 + 修复 |

### 语言风格检查点

**禁止使用**:
- ❌ "答案是..."
- ❌ "让我来..."
- ❌ "基于提供的信息..."
- ❌ "你说得对！"（除非确实正确）
- ❌ "这是个绝妙的想法！"（过度赞美）

**推荐使用**:
- ✅ 直接回答核心问题
- ✅ 使用代码引用（file:line）
- ✅ 量化性能数据
- ✅ 简短确认任务完成
- ✅ 主动但不越界

## 💡 三步质量保证流程

### 步骤 1: 回答前（计划）

```
问题分析
    ↓
确定问题类型（事实/解释/方案/任务）
    ↓
选择合适的回答长度和风格
    ↓
规划需要的工具和信息
```

### 步骤 2: 回答时（执行）

```
直接切入核心
    ↓
跳过无用开场白
    ↓
提供完整但简洁的信息
    ↓
使用精确的代码引用
```

### 步骤 3: 回答后（验证）

```
检查回答完整性
    ↓
评估是否可以更简洁
    ↓
确认是否需要后续行动
    ↓
简短确认（如适用）
```

## 🔍 使用建议

### 新手路径

1. 先阅读 **长度与风格指南** - 掌握基础回答格式
2. 查看决策树和对照表 - 知道什么时候用什么长度
3. 练习简单问题的简短回答

### 进阶路径

1. 学习 **工具与技巧指南** - 提升交互质量
2. 掌握渐进式详细策略
3. 练习上下文记忆和预判需求

### 专家路径

1. 研究 **错误与检查清单** - 精益求精
2. 使用自检清单评估每个回答
3. 持续改进回答质量

## 📋 质量自检简表

### 回答前

- [ ] 需要澄清细节？
- [ ] 长度是否匹配复杂度？

### 回答时
- [ ] 跳过无用开场白？
- [ ] 直接回答核心问题？
- [ ] 提供足够信息（不多不少）？

### 回答后

- [ ] 可以更简洁吗？
- [ ] 需要后续行动？
