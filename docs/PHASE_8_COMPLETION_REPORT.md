## 📋 使用建议

### 对于用户

**浏览资源时**:
```bash
cd components/agents/resources/devops-sre/
cat README.md  # 先阅读 README 了解概览
# 然后选择需要的具体文件
```

**寻找特定主题时**:
1. 查看主文件中的 📖 链接
2. 进入相应的 resources/ 目录
3. 阅读 README 找到对应的资源文件

**学习新领域时**:
1. 阅读主文件获得基础概念
2. 查看 README 了解资源全貌
3. 按学习路径逐个深入资源文件

### 对于维护者

**添加新资源文件时**:
1. 创建资源文件
2. 更新 README 的资源概览表
3. 添加到核心主题导航
4. 更新相关示例（如适用）

**重组资源目录时**:
1. 优先更新 README
2. 确保所有链接有效
3. 更新主文件的 📖 链接
