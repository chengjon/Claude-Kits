## 🔧 技术实现详情

### 新创建组件的技术规格

#### 1. SEO专家 (seo-specialist)
```yaml
---
description: 综合SEO专家，专注搜索引擎优化策略制定、关键词研究、技术SEO审核和网站性能优化。精通搜索引擎算法、页面优化、链接建设和数据分析，显著提升网站搜索排名和有机流量。
model: sonnet
name: seo-specialist
tools: Read, Write, Edit, Bash, Glob, Grep
---
```

**核心功能**:
- 搜索引擎策略制定和竞争分析
- 深度关键词研究和意图分析
- 技术SEO审核和页面优化
- 链接建设策略和实施
- SEO数据分析和效果监控

#### 2. 医疗健康工程师 (healthcare-engineer)
```yaml
---
description: 医疗健康工程师，专注医疗软件系统、HIPAA合规、数据安全和分析平台开发。精通电子健康记录、远程医疗、医疗物联网和临床决策支持系统构建，确保患者数据安全和医疗质量提升。
model: sonnet
name: healthcare-engineer
tools: Read, Write, Edit, Bash, Glob, Grep
---
```

**核心功能**:
- 医疗软件系统开发 (EHR, HIS, PACS)
- HIPAA/FDA合规实施
- 医疗数据安全和隐私保护
- 远程医疗平台开发
- 医疗IoT设备集成

#### 3. 教育科技工程师 (education-tech-engineer)
```yaml
---
description: 教育科技工程师，专注在线学习平台、虚拟教室、个性化学习系统和教育数据挖掘。精通LMS集成、学习分析工具、AR/VR教学应用和智能辅导系统开发，提升教育效果和学习体验。
model: sonnet
name: education-tech-engineer
tools: Read, Write, Edit, Bash, Grep
---
```

**核心功能**:
- 在线学习平台和LMS开发
- 虚拟教室和实时教学系统
- 个性化学习和AI辅导
- 学习数据分析和可视化
- AR/VR教学应用开发

### 组件质量标准

- **描述长度**: 150-200字符的专业中文描述
- **关键词覆盖**: 每个组件包含3-5个核心功能关键词
- **专业性**: 符合行业标准和最佳实践
- **可发现性**: 易于通过关键词搜索找到
- **互补性**: 与现有组件形成良好的功能互补
